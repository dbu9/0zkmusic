# The Phonetics of AI Singing

Hugo-ready page bundle for 0zkMusic.

## Contents

- `index.md` — complete article with front matter
- `feature.svg` — 1600×900 feature image
- `phonetic-window.svg` — note/phoneme allocation diagram
- `stress-alignment.svg` — linguistic and musical stress diagram
- `phonetic-test-matrix.csv` — reproducible experiment worksheet

## Installation

Copy the entire `phonetics-of-ai-singing` directory into the Hugo section used for articles. The Markdown uses page-relative asset paths, so keep the files together as a page bundle.

If the site’s archetype uses different taxonomy or hero-image parameters, merge the existing site front matter into `index.md`; the article body and asset references need no changes.
